# ☕ 浙大咖啡地图

玻璃质感主题的咖啡地图网页，展示浙江大学紫金港校区及周边的 55 家咖啡店。

## 功能

- 🗺️ **高德地图**：深色风格地图，支持拖拽、缩放
- 🔍 **关键词搜索**：实时筛选咖啡店名称，匹配文字高亮
- 🏷️ **品牌筛选**：星巴克 / 瑞幸 / 库迪 / 麦思威 / 独立咖啡
- 📏 **距离筛选**：1km / 3km / 5km 范围切换
- 📋 **排序切换**：按距离 / 按名称排序
- 📍 **标记展示**：咖啡杯标记在地图上显示店名
- 📝 **右侧详情面板**：点击店铺查看详细信息（地址、营业时间、设施、描述）
- 🧭 **一键导航**：跳转至高德地图导航
- 📱 **移动端适配**：手机端自动切换为底部抽屉式面板
- 🎨 **玻璃质感 UI**：毛玻璃 blur 效果、品牌渐变色、暗色主题

## 使用方法

### 本地预览

```bash
cd "浙江大学咖啡地图"
python3 -m http.server 8888
```

浏览器打开 `http://localhost:8888`

> 直接双击 `index.html` 可能因跨域限制无法加载地图，建议用本地服务器。

### 部署到 GitHub Pages

1. 在 GitHub 上创建一个新仓库
2. 将本文件夹上传到该仓库
3. 进入仓库 Settings → Pages
4. Source 选择 `main` 分支，根目录 `/ (root)`
5. 点击 Save，获得公开链接

## 数据来源

咖啡店数据来自 [早C晚A](https://coffee.philfan.cn)，基于 [Phil-Fan/zju-coffee](https://github.com/Phil-Fan/zju-coffee) 仓库的 YAML 数据。

## 技术栈

- 纯 HTML/CSS/JavaScript（无框架，无构建工具）
- 高德地图 JS API v1.4.15
- 玻璃质感 CSS（backdrop-filter、品牌渐变色）
